# Q&A evaluation status

`candidates.jsonl` contains 52 **unreviewed** source-derived candidates: three quoted-speaker questions and one artificial unanswerable question for each year, 2014–2026. The generator is `python -m scripts.build_eval_candidates`. These are useful for checking plumbing and Unicode, but quoted text and 1 January non-sitting dates make them far easier than natural public questions. They do not satisfy the 50–100 independently checked, varied release set in the plan. Every row has `reviewed: false`; the LangSmith upload path refuses such rows.

`results/exploratory.json` is the raw local run from 3 October 2026 using the complete 496,826-passage FTS index and the two-term evidence gate. Lexical baseline and LangGraph retrieval each reached recall@5 of **1.00** on the 39 positive candidates. All 13 artificial negatives returned `insufficient_evidence`, giving refusal correctness **1.00** for this set. Every citation ID was in the retrieved set. The graph returned `sources_only` for the positive questions because no Workers AI account was configured; claim support and answer quality were **not assessed**. Mean measured latency was **1,345 ms** for baseline retrieval and **1,390 ms** for the graph including retrieval and fallback; the slowest queries in this run took **3,866 ms** and **2,083 ms** respectively. A previous cold run took 17,307 ms on its first lexical query. This is too variable to claim free public readiness.

Before public launch, people need to write and check a separate held-out set spanning ordinary phrasing, Irish, cross-debate synthesis, ambiguity, genuine unanswerable requests, recent and older dates. They need to review whether each cited passage actually supports each claim. Run the model-connected comparison, log prompt and trace identifiers, and measure D1/Workers AI storage, latency, daily usage, and failure handling on free accounts. No Langfuse trace or LangSmith experiment exists yet because credentials have not been supplied. The evaluation script is `python -m scripts.evaluate_qa eval/candidates.jsonl --out eval/results/exploratory.json`; use `--langsmith-dataset` only after every question is independently reviewed.

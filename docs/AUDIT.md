# Repository audit, 3 October 2026

The served model is a 3.27 million parameter character decoder. Its manifest records 9,080 accepted speeches between 15 February and 25 April 1950 from a 1919–2013 archive. Generation and attention are served by FastAPI; the React frontend provides the Lab and a separate Research page. The Research pilot selects 2008–2011 speeches and keeps its weights and results separate from the served checkpoint. The original `dail_llm/rag/retriever.py` is a TF-IDF proof of concept over unattributed text chunks. It was not wired into the public API.

The Harvard Dataverse API for [DOI 10.7910/DVN/6MZN76](https://doi.org/10.7910/DVN/6MZN76) identifies Alexander Herzog and Slava Mikhaylov as authors. `outputs/dataset_manifest.json` incorrectly named Proksch and Slapin; this upgrade corrects that citation. The DOI and training data values are otherwise unchanged.

The app reports Python 3.12 as its minimum. CI runs Python 3.12 backend lint and tests, a Windows frontend build and browser suite, and two container smoke configurations. The local project virtual environment uses Python 3.13.3. The baseline non-integration unit suite passed 54 tests on this machine before the Q&A additions. The live [Vercel health endpoint](https://dail-llm.vercel.app/api/v1/health) returned version 0.2.0, ready, model loaded, and CPU on 3 October 2026. That check proves only the existing service was reachable, not that the new Q&A deployment is live.

New Q&A data is sourced from the [Oireachtas debates API](https://api.oireachtas.ie/v1/debates). Its records link to official Akoma Ntoso XML. The API's `chamber_id=dail` query returned zero results in a June 2026 check, while unfiltered records identified Dáil sittings by a chamber URI ending in `/house/dail`. The downloader therefore filters the observed metadata field. One 2016 sitting contains summaries but no speech nodes; a zero speech count is retained as source metadata, not treated as a parsing failure.

Local verification after the upgrade: 61 backend unit tests passed with one integration test deselected; Ruff passed; frontend lint, 42 unit tests, and production build passed. New desktop and mobile Playwright smoke tests passed with API responses mocked. A local API smoke against the full index returned HTTP 200, five attributed sources, valid citation IDs, and `sources_only` status in 1,183 ms. The latest-date downloader rerun and complete index rerun changed zero cached records and zero indexed days. Three sampled Official Report sitting links returned HTTP 200. Terraform 1.13.5 formatting and validation passed; an offline placeholder plan proposed 13 D1 databases, with no changes or destroys. Docker was not installed on this host, so container smoke tests could not be run. No authenticated Cloudflare, Langfuse, LangSmith, or Vercel deployment test has been completed.
